# Data Insight Solutions — website

The website of Data Insight Solutions, **built with [Reckons.AI](https://reckons.ai)**: pages are
written and reviewed in a knowledge graph, published as markdown, and edited in Sveltia CMS.

This repository holds the published site only. The knowledge behind it lives in a private, git-ignored
`workspace/`. See `AGENTS.md` for how the pieces fit and the rules agents follow here.
